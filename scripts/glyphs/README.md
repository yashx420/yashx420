Glyph outlines used by `../build.mjs` to draw text as shapes.

- `display.json`: Bricolage Grotesque (ExtraBold, opsz 96), SIL Open Font License, see OFL-BricolageGrotesque.txt
- `mono.json`, `mono-bold.json`: Space Mono, SIL Open Font License, see OFL-SpaceMono.txt

Regenerate with `python scripts/make_atlas.py`.
